# 📚 BookWise — AI-Based Book Recommendation System

A complete college project: a Flask web app with a **hybrid AI recommender** (content-based TF-IDF + item-based
collaborative filtering + popularity) that explains *why* each book is recommended.

| Layer | Technology |
|---|---|
| Frontend | HTML5, CSS3 (hand-written, responsive), vanilla JavaScript — no frameworks, works offline |
| Backend | Python 3.10+, Flask (Jinja templates + JSON REST API) |
| Database | SQLite (single file, zero setup) |
| ML | pandas, NumPy, SciPy, scikit-learn (TF-IDF, cosine similarity) |
| Tests | Python `unittest` (43 tests) |

## 1. Quick start (5 minutes)

```bash
# 1. Go into the project folder
cd book_recommender

# 2. (Recommended) create a virtual environment
python -m venv venv
venv\Scripts\activate            # Windows
source venv/bin/activate         # macOS / Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the app  (a ready-to-use database is already included)
python run.py
```
Open **http://127.0.0.1:5000** → log in with **username `demo` / password `demo1234`** or create your own account.

### Rebuild everything from scratch (the full ML pipeline)
```bash
python -m ml.make_sample_data      # creates data/raw/books.csv + ratings.csv  (offline sample dataset)
python -m ml.preprocess            # cleans data  -> data/processed/*.csv  (prints a cleaning report)
python -m ml.evaluate              # evaluates the models -> data/processed/evaluation_results.csv
python scripts/init_db.py --reset  # builds data/bookrec.db  (books + 400 seed readers + their ratings)
python run.py
```

### Run the tests
```bash
python -m unittest discover -s tests -t . -v
```

## 2. ⚠️ About the dataset (please read)
* **Included sample data:** ~99 real, famous books with short *original* descriptions written for this project, plus
  **synthetic** ratings from 400 imaginary readers (generated by `ml/make_sample_data.py`). This lets the project run
  offline in seconds and makes every demo reproducible. **Say this clearly in your report/viva.**
* **Real public dataset (recommended for the final report):** *Goodbooks-10k* — see `docs/02_dataset_and_ml.md`
  for download + the 3-command switch (`python -m ml.preprocess --raw <folder> --max-users 5000`).
  The pipeline supports its file format; I could not download it in my build environment, so you should run it once on
  your machine and paste your own evaluation numbers into the report.

## 4. Suggested live-demo script (5 minutes)
1. Home page → show stats and top-rated books.
2. **Register** a new user, tick 2 genres → open **For You**: cold-start recommendations with 💡 reasons.
3. Open a book → **rate 5★** two or three books of one genre, ♥ favourite one.
4. Back to **For You** → recommendations change; point out "Similar to … which you liked" and "Readers who liked … also liked".
5. Browse → search + filter by genre/rating/author.
6. **History** and **Profile** pages (activity log, detected taste).
7. Show `docs/04_testing.md` results and `python -m ml.evaluate` output.

## 5. Deployment
* **Local (default):** `python run.py`.
* **Production-style:** `pip install gunicorn` → `SECRET_KEY="long-random-string" gunicorn -w 1 -b 0.0.0.0:8000 "app:create_app()"`
  (use `-w 1` or a shared model store, because each worker keeps its own in-memory recommender).
  Free hosts such as PythonAnywhere or Render work for demos. Set `debug=False` (do **not** use `run.py` in production).
* Windows tip: if `python` is not found, use `py`.

## 6. Troubleshooting
| Problem | Fix |
|---|---|
| `ModuleNotFoundError` | activate the venv and run `pip install -r requirements.txt` |
| "Processed data not found" | run `python -m ml.make_sample_data && python -m ml.preprocess` |
| "Database already contains books" | run `python scripts/init_db.py --reset` |
| Port 5000 busy (macOS AirPlay) | change the port in `run.py` |
| Want a clean demo | `python scripts/init_db.py --reset` |
